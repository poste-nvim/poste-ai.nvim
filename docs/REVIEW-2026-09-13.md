## Bugs fixed

1. **A message-less session file crashed every append path**
   (`chat/session.lua` `load`) — a hand-edited or partially-written
   session JSON with a bare session object loaded as-is, and every
   subsequent append (`s.messages[#s.messages + 1] = …` in stream.lua,
   session.append_record) indexed nil. `load` now coerces a missing
   `messages` to `{}` so restore-then-continue just works.

2. **`conversation.messages()` dropped `ts` from the persistence shape**
   (`chat/conversation.lua`) — the declared "shape suitable for
   persistence" silently discarded timestamps, so a round-trip through it
   broke `matches_messages` equality (needless full repaint on every
   reopen) and restored messages rendered with fresh "now" stamps. `ts`
   is exported now; live sessions were never affected (they persist the
   stored tables directly).

3. **`<C-Space>` @mention completion was never installed**
   (`chat/window.lua`, `config.lua`) — `input_key()` takes one argument,
   so the default it was passed (`"<C-Space>"`) was silently discarded;
   `complete_mention` was also absent from the default `keymaps.chat_input`
   table, so `get_keymap` returned nil and `map()` skipped the binding.
   `M.trigger_mention` was unreachable dead wiring and the `g?` help hid
   the row. The action is now registered in the defaults and `input_key`
   forwards a default; docs already documented the key (they were
   describing the intent the code failed to wire).

## Feature

4. **`/help` slash command** (`chat/slash.lua`) — the keymap cheat sheet
   had exactly one entry point (`g?`, conversation pane only). Typing `/`
   in the input now lists `/help` alongside `/new` `/session` `/models`,
   so the palette itself points you at the help. doc-poste's chat page
   gained the missing built-in slash-command table.

## Recorded, not changed (with rationale)

- **`resolve_all`'s 10s per-ref timeout holds `st.pending` until it
  fires** — carried: by design, a hung mention resolver must not wedge
  sends forever.
- **`text.truncate` with limit < 3 returns "..." wider than the limit** —
  carried from 09-06; no caller passes such limits.
- **slash command filtering stays prefix-based** — commands are a short
  fixed list; carried.
- **`popup.close()` keeps `st.buf` alive for reuse** — intentional
  create-once reuse, carried.
- **`mention.complete` items fall back to `word = c` for label-less
  candidate tables** — providers pass `{label, description}`; hardening
  would paper over a provider contract violation.
- Carried unchanged from 09-06/07/08/09/11/12: `/new` during compose
  discards the typed message; API key in curl argv (never logged);
  `session.list()` decodes every file; popup/window shadowing of
  `<C-n>`/arrows safe by construction.
